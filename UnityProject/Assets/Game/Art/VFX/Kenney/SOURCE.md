# Player attack particle textures

Source: [Kenney Particle Pack](https://kenney.nl/assets/particle-pack). The archive's license file identifies version 1.1 and [CC0](https://creativecommons.org/publicdomain/zero/1.0/). Original license text is preserved in `License.txt`.

Only four transparent PNGs are included: `star_01.png` for short spear sparks, `dirt_01.png` for foot debris, `smoke_03.png` for the breakthrough wind trail, and `circle_02.png` for small impact rings. The original PNG files are unchanged. `PlayerAttackVfx` uses them with Unity's built-in ParticleSystem; there is no sound.
