# 赵云步战 Demo：首张精灵导入与验收

此文保留初始静态原图的检查结果与建议参数，不代表现有工程尚未导入资源。实际设置以工程中的 TextureImporter 与 Editor 工具为准；后续动作与验证见 [ART_ASSETS](../UnityProject/Docs/ART_ASSETS.md) 与 [VALIDATION](../UnityProject/Docs/VALIDATION.md)。

本说明对应斜俯视持枪待机样板第三版。它是单张静态姿态，不是动画。当前未在 Unity 内运行，不应视为正式资源验收通过。

## 已完成的文件检查

包内文件：ArtSource/Prototype/ZY_Idle_SE_Prototype_v03.png。原始文件名见 ASSET_MANIFEST.json。

尺寸为 1536 × 1024，模式为 RGBA。约 73.35% 像素完全透明，约 2.23% 像素的透明度数值位于 1 至 240，其余像素主要位于 241 至 254。没有完全不透明的 255 像素，主体有轻微整体透明，正式制作前需判断是否修正。

非零透明度范围接触图像下边缘；透明度至少为 32 的范围为 x=204 至 1481、y=18 至 983，坐标从左上角起算。这说明主体之外存在低透明度残留，不能仅凭文件有透明通道就判定边缘合格。

造型也有偏移：相较最初设定，当前披风更鲜艳，甲胄偏暖。仅用于导入测试，正式母版仍以角色设定图的低饱和银灰甲与青蓝披风为准。

## 建议导入设置

在 Unity 6 项目中建立 Assets/Game/Art/Characters/ZhaoYun/Prototype 目录，将下载的样板放入并命名为 ZY_Idle_SE_Prototype.png。先保留原图，避免覆盖。

| 属性 | 建议起始值 | 说明 |
| --- | --- | --- |
| Texture Type | Sprite (2D and UI) | 二维角色精灵 |
| Sprite Mode | Single | 当前只有一张姿态 |
| Pixels Per Unit | 400 | 仅为本图测试起点；跨资源统一尺度后再锁定 |
| Mesh Type | Full Rect | 先避免细枪杆与缨穗被自动轮廓裁切 |
| Alpha Source | Input Texture Alpha | 使用图片自身透明通道 |
| Alpha Is Transparency | 开启 | 降低透明边缘过滤伪影；不能去掉已有光晕 |
| Filter Mode | Bilinear | 适用于本图非像素风表现 |
| Wrap Mode | Clamp | 测试阶段使用 |
| Generate Mip Maps | 关闭 | 固定镜头的起始方案，缩放闪烁时再评估 |
| Max Size | 2048 | 避免本图被导入时降尺寸 |
| Compression | None | 先排除压缩导致的边缘问题，正式版再优化 |
| Pivot | Custom，约 X=0.45、Y=0.17 | 目测双脚接地中点的测试值，不是测量定稿 |

Pivot 坐标以图片左下角为原点。不要设在图片底边中央，图片边界受长枪和透明留白影响，不能代表人物站立位置。后续每帧都以同一个角色接地基准对齐。

官方属性说明：https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/textures/textures-reference/texture-type-sprite

## 最小测试场景

1. 新建名为 ArtValidation 的场景，保存到 Assets/Game/Scenes/Tests。
2. 使用正交相机，正对二维 XY 平面，保持精灵无倾斜。图片已经画入俯视透视，不要再次倾斜相机来模拟同一俯视角。
3. 将精灵拖入场景，Transform Scale 保持 1。测试时使用项目可用的 Sprite Unlit 材质，排除额外灯光影响。
4. 依次用浅灰、深灰、灰褐色相机背景观察轮廓，重点检查披风、两腿之间、枪杆、白缨和脚下。
5. 以约 128、160、192 像素的屏幕人物高度观察清晰度。这些数值指人物投影高度，不是整张图的宽度；调整相机尺寸即可，无需修改源图。
6. 用一个简单地面标记对准 Pivot。移动角色时检查接地点，而不是用武器尖端或衣摆作基准。
7. 先不建立武器碰撞体。正式战斗中的攻击范围应由战斗逻辑单独控制，移动碰撞体应靠近脚底，不能覆盖整张图片。

## 验收标准

| 项目 | 通过条件 | 当前状态 |
| --- | --- | --- |
| 文件透明通道 | 包含有效 Alpha | 已确认 |
| 干净边缘 | 三种底色下无可见雾边或杂点 | 待 Unity 验证 |
| 主体不透明度 | 不因背景变化出现明显透色 | 待验证，主体 Alpha 最高为 254 |
| 实际尺寸辨识度 | 缩小后可分辨头盔、披风、双手和枪杆 | 待验证 |
| 脚底锚点 | 与地面接触自然，移动不漂浮 | 待验证 |
| 视角匹配 | 与关卡地面和敌兵使用同一投影 | 待验证 |
| 造型与配色 | 对照角色设定图保持一致 | 有偏移，需要修整 |
| 动画能力 | 连续帧保持身份与接地一致 | 尚未制作 |

## 下一制作节点

先完成这张静态样板的边缘、色彩与投影验收，再制作同一朝向的直刺准备、刺出、收招三个关键姿势。关键姿势用于检验动作关系，不应直接称为流畅动画；通过后再决定补帧或分层骨骼方案。

保留原始设定图为母版，每次制作都引用母版，避免连续引用上一版而累积造型偏移。每轮仅改一个问题，并保存新版本。
