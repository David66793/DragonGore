# 验收清单

每项标记通过、失败或未测试，并记录证据。不得把静态代码检查写成运行通过。

## 工程

Unity 实际版本有记录；依赖解析成功；C# 编译零错误；场景无 Missing Script；初始化重复运行不产生重复对象；用户改动不被覆盖；.meta 由 Unity 生成并管理。

## 游戏

移动方向与斜向速度正确；攻击范围可理解；一次攻击不重复伤害同一目标；敌人预警与伤害时机一致；死亡敌人不继续攻击；暂停冻结战斗；救援前或精英未击败时不能胜利；完成目标可撤离；玩家死亡进入失败；连续重开三次无残留敌人、计时器、事件监听或错误目标状态。

## 视觉

角色对照母版无明显配色与造型漂移；浅灰、深灰、灰褐底色下无可见雾边；缩小后枪杆、白缨与双手仍可辨认；锚点稳定；道具遮挡按脚底排序；没有缺字；单张姿态的方向限制明确记录。

## 性能与构建

性能数据必须附实际机器、分辨率和敌人数。未测试不能保证帧率。Windows 构建需要正确模块；若未构建，给出原因与下一步。主菜单、胜负、重开在独立构建中复查后才记为构建验收通过。
