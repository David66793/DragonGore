# 游戏需求与范围

## 用户已确认

Unity 6；2D 与伪 3D 表现；三国题材；赵云长坂坡之战 Demo；偏写实武侠风；先做步战；当前完全不制作声音。目标是新手借助 AI 完成结构清晰、美术统一、逐步接近小型商业游戏完成度的作品。

## 建议默认值，允许在实现中合理调整

Windows 键鼠，固定斜俯视镜头，5～8 分钟体验。普通攻击、闪避、破阵突刺；近战兵、弓兵、出口精英。村口进入、废墟救援阿斗、增援突围、撤离胜利。采用演绎设定，不声称严格历史复原；不用蜀字旗作为当前时间点的正式资产。

## 实施顺序

M0：检测环境、创建项目、代码编译、场景可打开。
M1：灰盒移动、攻击、受击、敌人、死亡和重开。
M2：救援、增援、出口条件、胜利，形成完整闭环。
M3：导入静态角色，建立美术检查场景，确认比例、边缘与遮挡。
M4：在母版基础上逐步替换敌人、环境与动画，打磨体验。

首轮执行应尽可能完成 M0～M3，不以正式资源缺失为由停止灰盒工作。M4 需要新资源生产，不在本包中假定已经完成。

## 后续动画计划

先固定一个方向，验证待机、行走、直刺、受击。直刺先做准备、刺出、收招关键姿势，再决定补帧或分层骨骼。四向或八向素材数量依据实际生产质量决定。八向移动不代表已有八向动画。
